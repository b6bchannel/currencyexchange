# Currency

一个基于新拟态 UI 的简易多向汇率转换 Web App。专为 iOS Safari 设计，支持作为 PWA（渐进式网页应用）添加到主屏幕全屏使用，无广告，不依赖付费开发者账号。

---

## 功能特性

* **新拟态 UI**：完全依靠高光和软阴影构建空间感，数字输入框使用加深色调（#D5DFEB）以增强视觉层级。
* **多向联动**：点击任意币种输入框即可直接唤起手机数字键盘，输入金额时，其他所有卡片的数据毫秒级同步计算。
* **微信级手势操作**：卡片无常驻易误触按钮。左滑卡片平移露出**绿色添加键 (+)**，右滑卡片平移露出**红色删除键 (✕)**。
* **排序与刷新**：右上角配备独立按钮，支持手动调整卡片前后顺序，以及手动点击 ↻ 强制拉取最新汇率。
* **防干扰处理**：注入 `touch-action: pan-y` 属性，彻底锁死 iOS 浏览器的横向回弹与系统侧滑干预。
* **世界时间集成**：各币种卡片内嵌当地精确系统时间，自动解析 AM/PM 格式并附带 GMT 时区偏移量。
* **双节点容灾与离线模式**：
  * 聚合 jsDelivr CDN 主节点与 Cloudflare 备用节点，主节点请求失败、响应异常或超过 8 秒未完成时自动切换。
  * 首次加载后将汇率表、卡片顺序及最后一次输入的数值存入本地 LocalStorage。页面已加载时，无网状态下仍可使用有效的缓存汇率计算；当前未配置 Service Worker，不保证断网后重新启动页面。

## 已适配币种

支持 61 种货币，按地区分组，可自由添加、删除和排序：

* **东亚 & 东南亚**：CNY（人民币）、HKD（港币）、MOP（澳门元）、TWD（新台币）、JPY（日元）、KRW（韩元）、SGD（新加坡元）、THB（泰铢）、VND（越南盾）、MYR（马来西亚林吉特）、IDR（印尼盾）、PHP（菲律宾比索）、KHR（柬埔寨瑞尔）、LAK（老挝基普）、MNT（蒙古图格里克）
* **中亚**：KZT（哈萨克斯坦坚戈）、UZS（乌兹别克斯坦苏姆）、KGS（吉尔吉斯斯坦索姆）、TJS（塔吉克斯坦索莫尼）、TMT（土库曼斯坦马纳特）
* **南亚**：INR（印度卢比）、PKR（巴基斯坦卢比）、BDT（孟加拉塔卡）、LKR（斯里兰卡卢比）、NPR（尼泊尔卢比）
* **欧洲**：EUR（欧元）、GBP（英镑）、CHF（瑞士法郎）、PLN（波兰兹罗提）、SEK（瑞典克朗）、NOK（挪威克朗）、DKK（丹麦克朗）、HUF（匈牙利福林）、CZK（捷克克朗）、TRY（土耳其里拉）、RUB（俄罗斯卢布）、RON（罗马尼亚列伊）、ISK（冰岛克朗）
* **美洲**：USD（美元）、CAD（加币）、MXN（墨西哥比索）、BRL（巴西雷亚尔）、ARS（阿根廷比索）、CLP（智利比索）、COP（哥伦比亚比索）、PEN（秘鲁索尔）
* **大洋洲**：AUD（澳元）、NZD（新西兰元）、FJD（斐济元）
* **中东**：AED（阿联酋迪拉姆）、SAR（沙特里亚尔）、QAR（卡塔尔里亚尔）、KWD（科威特第纳尔）、BHD（巴林第纳尔）、OMR（阿曼里亚尔）、ILS（以色列新谢克尔）
* **非洲**：ZAR（南非兰特）、EGP（埃及镑）、MAD（摩洛哥迪拉姆）、KES（肯尼亚先令）、NGN（尼日利亚奈拉）

新增币种通过右上角 **+** 或左滑卡片添加；已有卡片、顺序和输入金额会保留，不会自动向面板添加所有币种。

各币种时间采用所配置代表城市的 IANA 时区；跨时区国家以该城市为准。若缓存或接口缺少某币种的有效汇率，该卡片显示“汇率暂不可用”并暂停输入，其他币种仍可正常换算；联网后点击 ↻ 重试。

## 安装到桌面步骤

1. 在 iPhone 上使用 **Safari 浏览器** 打开你的 GitHub Pages 链接。
2. （若图标未正常抓取，请强制刷新一次页面）。
3. 点击 Safari 底部工具栏正中间的 **“分享” 按钮**（带有向上箭头的方块）。
4. 在菜单中向下滚动，点击 **“添加到主屏幕” (Add to Home Screen)**。
5. 点击右上角“添加”，即可在桌面生成高清图标并隐藏浏览器地址栏全屏使用。
